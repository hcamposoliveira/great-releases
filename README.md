# GREAT Editor installers

Internal After Effects panel for the Studio Great team. Requires a team license key.

| System  | Installer |
|---------|-----------|
| macOS   | [GREAT_Editor_Mac.pkg](https://github.com/hcamposoliveira/great-releases/raw/main/GREAT_Editor_Mac.pkg) |
| Windows | [GREAT_Editor_Windows.exe](https://github.com/hcamposoliveira/great-releases/raw/main/GREAT_Editor_Windows.exe) |

After installing, restart After Effects and open **Window > Extensions > GREAT Editor**.

Windows may show "Windows protected your PC" because the installer is not code-signed yet.
Click **More info**, then **Run anyway**.

Current version: 3.3
